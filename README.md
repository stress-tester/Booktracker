### Booktracker
# GitHub User Finder
## Автор: Холодов Дмитрий Иванович

### Описание
Приложение позволяет планировать тренировки с возможностью фильтрации по дате и типу тренировки. Все данные сохраняются в формате JSON.

## Запуск скрипта
### Через терминал:
`python booktracker.py` или `python3 booktracker.py`
### Через любую IDE
Python, Visual Studio, Pycharm и т.д

### Примеры использования
1. Введите дату, тип тренировки и длительность.
2. Нажмите кнопку "Добавить тренировку".
3. Для фильтрации введите тип или дату, затем нажмите "Применить фильтр".
