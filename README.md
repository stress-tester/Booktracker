### Booktracker
# GitHub User Finder
## Автор: Холодов Дмитрий Иванович

### Описание
Приложение позволяет искать пользователей GitHub по их никнейму и сохранять их в избранное.

### Как использовать API
Используйте GitHub REST API для получения информации о пользователях. Примеры запросов можно найти в [GitHub API Documentation](https://docs.github.com/rest).

### Зависимости:
requests (рекомендуется установить через `pip install requests`

### Запуск скрипта
# Через терминал:
`python booktracker.py` или `python3 booktracker.py`
# Через любую IDE


### Примеры использования
1. Введите никнейм пользователя в поле поиска.
2. Нажмите кнопку "Поиск".
3. Результаты поиска будут отображены в списке.
4. Выберите пользователя и нажмите "Добавить в избранное".
